Documentación técnica del proyecto

El repositorio reúne la especificación contractual y técnica completa del Módulo de Planes de Trabajo Docentes (PTD) de la IE Las Palmas. Está construido sobre el Documento de Análisis de Requerimientos de Software v1.0 y sobre el estudio de las plantillas reales del Plan de Aula vigentes en la institución (PLAN DE AULA 2026 ESPAÑOL.xlsx y PENSAMIENTO SOCIAL.xlsx).

Orden de lectura sugerido

Si va a leer los documentos en orden, este es el recomendado:

  1. SRS — Especificación de Requisitos de Software (IEEE 29148) El documento maestro. Describe el producto, requisitos funcionales y no funcionales, y la estructura real del Plan de Aula (§10).
  2. Casos de uso e historias de usuario Detalle observable del comportamiento que el sistema debe tener, por actor (docente, coordinación, rector, admin).
  3. Reglas de negocio Invariantes verificables (RN-###) que el sistema debe cumplir en todo momento.
  4. Modelo de dominio (DDD) Bounded contexts, agregados, value objects y puertos. El pilar del código backend.
  5. Diagrama de arquitectura Vista C4 + hexagonal (Ports & Adapters), despliegue y cross-cutting concerns.
  6. Esquema de base de datos (DDL PostgreSQL) Fuente de verdad de la persistencia relacional con sus relaciones y ER.
  7. Especificación de API Contrato REST/JSON de servicios, con códigos de error PTD-XXX trazables.
  8. Backlog inicial y roadmap Épicas E0..E12, historias de usuario, definition of ready y definition of done.

Convenciones de identificación

  • RF-### — Requisitos funcionales (SRS §7.1)
  • RNF-### — Requisitos no funcionales (ISO 25010)
  • RC-### — Requisitos de cumplimiento
  • RD-### — Requisitos de datos
  • RI-### — Requisitos de interfaces externas
  • RN-### — Reglas de negocio
  • UC-### — Casos de uso
  • HU-x.y — Historias de usuario por épica
  • PTD-###-XXXX — Códigos de error de API
  • E0..E12 — Épicas del backlog
